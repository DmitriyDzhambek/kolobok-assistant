# Как запустить «Колобка» у себя на рабочем столе (Windows 10/11)

Это React веб-сервис (Vite + React 18 + TypeScript) + необязательный Python-бэкенд
для автокликера (запись и повтор макросов мыши). Голос — Web Speech API браузера,
задачи — localStorage, погода — open-meteo (без ключей и без регистрации).

## 1. Что нужно поставить один раз

- Node.js 18 или новее: https://nodejs.org (вариант LTS). Проверка: `node -v`.
- Google Chrome или Microsoft Edge (нужны для распознавания речи).
- Для автокликера (не обязательно): Python 3.9+ с https://www.python.org/downloads/
  — при установке обязательно поставьте галочку «Add Python to PATH». Проверка: `python --version`.

## 2. Запуск из исходников

Распакуйте архив, откройте папку проекта в терминале
(в папке: Shift + правая кнопка мыши → «Открыть окно PowerShell здесь») и выполните:

```powershell
npm install
npm run dev
```

Терминал покажет адрес вида `http://localhost:5173/`. Откройте его в Chrome.

Важно: именно `localhost` браузер считает безопасным контекстом, поэтому
микрофон заработает без HTTPS. Chrome спросит разрешение на микрофон — нажмите
«Разрешить». Если звука нет: Параметры Windows → Конфиденциальность → Микрофон →
разрешить доступ приложениям и настольным приложениям.

## 3. Установка как приложение на рабочий стол (PWA)

На странице в Chrome: меню (⋮) → «Установить Колобок…» либо кнопка
«⤓ Установить на рабочий стол» в шапке приложения. Появится отдельное окно
и ярлык на рабочем столе.

Автозапуск при включении компьютера: Win+R → `shell:startup` → положите в эту
папку ярлык установленного приложения.

Замечание: dev-сервер (`npm run dev`) при этом должен быть запущен. Если хотите,
чтобы приложение работало без терминала — используйте сборку из папки `dist`
(пункт 4) или опубликуйте сервис по HTTPS.

## 4. Готовая сборка (папка `dist` в архиве)

Сборка уже сделана, её можно раздавать любым статическим сервером:

```powershell
npm install
npx vite preview
```

Либо пересобрать заново: `npm run build`.

Микрофон в браузере работает только на `localhost` или по HTTPS. Если откроете
`dist/index.html` двойным щелчком (протокол `file://`), голос и service worker
работать не будут — это ограничение браузеров, а не ошибка кода.

## 5. Команды проверки

```powershell
npx tsc --noEmit          # проверка типов
npm run build             # production-сборка
```

## 6. Что умеет (голосом или текстом в поле ввода)

- «открой ютуб / почту / озон» — откроет сайт;
- «найди рецепт борща» — поиск в интернете;
- «таймер на 10 минут», «таймер через полчаса» — таймер с голосовым звоном;
- «напомни позвонить маме через час» — напоминание;
- «задача: сдать отчёт», «список задач», «выполнено отчёт» — список задач (сохраняется в браузере);
- «посчитай 25*4+10», «который час», «какое сегодня число»;
- «погода в Твери», «какая погода в Питере» — погода без ключей API;
- «записать макрос», «запусти макрос 10 раз», «останови макрос» — автокликер (см. пункт 7);
- «расскажи сказку / шутку / пословицу», «помощь», «кто ты».

Кнопка микрофона: нажать — говорить, удерживать (или пробел) — длинная диктовка,
отпустить — отправить.

## 7. Автокликер: запись и повтор макросов (для игрового контента)

Колобок умеет записывать ваши действия мышью (движения, клики, скроллы и паузы
между ними) и повторять их заданное количество раз — как Kofge-Clicker.
Эта часть работает через локальный Python-бэкенд `backend/macro_server.py`,
потому что браузер не может управлять мышью вне своей вкладки.

### Запуск бэкенда (один раз настроить, потом двойной клик)

Проще всего: двойной клик по файлу `backend/start_backend.bat` — он сам создаст
виртуальное окружение, установит зависимости и запустит сервер на
`http://127.0.0.1:8765`. Окно терминала должно оставаться открытым, пока
вы пользуетесь автокликером.

Вручную (PowerShell в папке `backend`):

```powershell
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python macro_server.py
```

### Как пользоваться

1. В приложении Колобка нажмите кнопку 🖱️ на нижней панели — откроется
   «Автокликер-макрос». Индикатор станет жёлтым («Готов к записи»), если бэкенд запущен.
2. Нажмите «● Записать макрос» (или скажите голосом «записать макрос»).
3. Переключитесь в игру и сделайте нужные действия мышью.
4. Нажмите **F8 или ESC** — запись остановится и сохранится в `backend/macros/macro.json`.
5. Укажите «Повторов» (сколько раз повторить) и нажмите «▶ Запустить»
   (или скажите «запусти макрос 10 раз»).
6. Экстренный стоп воспроизведения: **F9** или резко увести мышь в левый верхний
   угол экрана (failsafe pyautogui).

### Голосовые команды автокликера

- «записать макрос» / «запиши макрос» — начать или остановить запись;
- «запусти макрос 10 раз», «повтори макрос пять раз» — воспроизведение с числом повторов;
- «останови макрос» — стоп любой операции.

### Важно знать

- Сервер слушает только `127.0.0.1` — он недоступен из интернета, мышью могут
   управлять лишь программы на вашем компьютере;
- запись и воспроизведение идут на уровне системы: клики попадают в любое окно
   (игру, браузер) — именно поэтому останавливать удобно горячими клавишами;
- в некоторых играх с античитом автоматизация кликов может нарушать правила игры —
   используйте ответственно;
- если панель показывает «Бэкенд не запущен» — запустите `start_backend.bat`
   и подождите пару секунд (панель опрашивает сервер каждые 1,2 с);
- адрес бэкенда можно поменять переменной окружения фронтенда
   `VITE_MACRO_API_URL` (по умолчанию `http://localhost:8765`), порт сервера —
   переменной `KOLOBOK_MACRO_PORT`.
