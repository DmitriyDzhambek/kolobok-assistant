# Как запустить «Колобка» у себя на рабочем столе (Windows 10/11)

Это React веб-сервис (Vite + React 18 + TypeScript), а не exe-программа.
Серверной части нет: голос — Web Speech API браузера, задачи — localStorage,
погода — open-meteo (без ключей и без регистрации).

## 1. Что нужно поставить один раз

- Node.js 18 или новее: https://nodejs.org (вариант LTS). Проверка: `node -v`.
- Google Chrome или Microsoft Edge (нужны для распознавания речи).

## 2. Запуск из исходников

Распакуйте архив, откройте папку проекта в терминале
(в папке: Shift + правая кнопка мыши → «Открыть окно PowerShell здесь») и выполните:

```powershell
npm install
npm run dev
```

Терминал покажет адрес вида `http://localhost:5173/`. Откройте его в Chrome.

Важно: именно `localhost` браузер считает безопасным контекстом, поэтому
микрофон заработает без HTTPS. Chrome спросит разрешение на микрофон — нажмите
«Разрешить». Если звука нет: Параметры Windows → Конфиденциальность → Микрофон →
разрешить доступ приложениям и настольным приложениям.

## 3. Установка как приложение на рабочий стол (PWA)

На странице в Chrome: меню (⋮) → «Установить Колобок…» либо кнопка
«⤓ Установить на рабочий стол» в шапке приложения. Появится отдельное окно
и ярлык на рабочем столе.

Автозапуск при включении компьютера: Win+R → `shell:startup` → положите в эту
папку ярлык установленного приложения.

Замечание: dev-сервер (`npm run dev`) при этом должен быть запущен. Если хотите,
чтобы приложение работало без терминала — используйте сборку из папки `dist`
(пункт 4) или опубликуйте сервис по HTTPS.

## 4. Готовая сборка (папка `dist` в архиве)

Сборка уже сделана, её можно раздавать любым статическим сервером:

```powershell
npm install
npx vite preview
```

Либо пересобрать заново: `npm run build`.

Микрофон в браузере работает только на `localhost` или по HTTPS. Если откроете
`dist/index.html` двойным щелчком (протокол `file://`), голос и service worker
работать не будут — это ограничение браузеров, а не ошибка кода.

## 5. Команды проверки

```powershell
npx tsc --noEmit          # проверка типов
npm run build             # production-сборка
```

## 6. Что умеет (голосом или текстом в поле ввода)

- «открой ютуб / почту / озон» — откроет сайт;
- «найди рецепт борща» — поиск в интернете;
- «таймер на 10 минут», «таймер через полчаса» — таймер с голосовым звоном;
- «напомни позвонить маме через час» — напоминание;
- «задача: сдать отчёт», «список задач», «выполнено отчёт» — список задач (сохраняется в браузере);
- «посчитай 25*4+10», «который час», «какое сегодня число»;
- «погода в Твери», «какая погода в Питере» — погода без ключей API;
- «расскажи сказку / шутку / пословицу», «помощь», «кто ты».

Кнопка микрофона: нажать — говорить, удерживать (или пробел) — длинная диктовка,
отпустить — отправить.
